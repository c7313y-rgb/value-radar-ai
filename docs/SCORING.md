# スコアリング仕様

すべての計算は `engine/scoring/` にあります。この文書はその意図を説明します。

## 1. なぜ単純平均を使わないのか

PER（小さいほど良い、分布は右に長い裾）と ROE（大きいほど良い、業種で水準が違う）を
そのまま平均すると、次の3つが同時に起きます。

1. 単位の違う数値が混ざり、重みが実質的に不定になる
2. 業種の水準差が「その企業の優劣」に化ける（銀行のPBRと半導体のPBRは比較できない）
3. 1銘柄の外れ値がスケールを支配する

対策は3段です。

```
① ピアグループ内で z 値      … 業種 × 地域。母集団8社未満なら 業種 → 全体 へフォールバック
② winsorize ±2.5σ           … 外れ値を切る
③ ロジスティック写像で 0-100 … 100 / (1 + exp(-1.10 z))   z=0→50, z=+2→約90
```

レイヤー内で複数指標を平均すると分散が縮み、全銘柄が50点付近に潰れます。
そこで順位関係を変えない拡張係数 `LAYER_SPREAD = 1.45` を掛けて 0–100 のレンジを使います。

## 2. 欠損の扱い

**欠損を平均値で埋めません。** 埋めると「データが無い」ことが「平均的である」に化けます。

```
レイヤー得点 = Σ(得点 × 重み) / Σ(取得できた指標の重み)     ← 欠損分の重みを再配分
レイヤーカバレッジ = Σ(取得できた重み) / Σ(全重み)          ← 確信度の材料になる
```

したがって **欠損があってもスコアは下がらず、確信度が下がります。**（テストで固定）

## 5. 確信度（0.55–1.00）

```
raw  = 0.32×データ網羅性 + 0.24×指標カバレッジ + 0.28×委員会一致度 + 0.16×利益安定性
conf = 0.55 + 0.45 × raw
      （デモ合成データの場合はさらに ×0.92）
```

委員会の一致度は6エージェントのスタンス分散から求めます。意見が割れるほど確信度が落ちます。
デモデータであること自体を確信度に反映させているのは、正直さの一貫性のためです。

## 6. 適正価値（フェアバリュー）

単一手法は必ず外すため、3つの独立した見方を加重平均します。

| 手法 | 重み | 内容 |
|---|---:|---|
| ピア相対PER法 | 0.45 | ピア中央値PER × 品質補正(±55%) × 成長補正(±45%) |
| FCF利回り法 | 0.30 | 要求FCF利回り（ピア中央値を品質で調整）まで価格が動くとみなす |
| 成長織り込み法 | 0.25 | PEG = 1.5 を妥当上限とみなす（上限PER 55倍） |

結果は現在株価の 0.40〜2.00 倍にクリップします（モデル誤差を利益に見せないため）。

### 株価が織り込む成長年数

```
PER_now / (1+g)^n = 18   を n について解く
```

Contrarian Analyst の主要な反論材料です。n が5年を超えると減点が入ります。

### 購入検討価格帯

```
安全域 MOS = 18% + (リスク減点 / 25) × 22%      → 18〜40%
上限 = 適正価値 × (1 − MOS)
下限 = 上限 × 0.90
（現在株価が既に下限を割っていれば、帯を現在株価近傍へ寄せる）
```

## 7. グレードと投資判断

```
企業評価スコア = 0.32×Quality + 0.20×Growth + 0.26×Governance + 0.22×Trend
グレード帯     = S:78+  A:68+  B:57+  C:45+  D:45未満
```

価格評価は Value レイヤーのグレードに、割高キャップ（README 1-3 の表）を適用したもの。

| 最終判断 | 条件 |
|---|---|
| 本日の有力候補 | 最終点 68以上 かつ 企業 S/A かつ 価格 S/A |
| 検討候補 | 最終点 58以上 かつ 価格 S/A/B |
| 良い会社・価格待ち | 企業 S/A だが 価格 C/D |
| 監視 | 最終点 48以上 |
| 見送り | それ以外 |

## 8. ★（初心者向け）

最終点から、年率ボラティリティ45%/60%超、時価総額30億USD未満、
平均売買代金30百万USD未満、リスク減点12超 でそれぞれ減点したうえで5段階に丸めます。
**スコアが高くても、値動きが荒く流動性が薄ければ★は増えません。**

## 9. 拡張したいとき

- 指標を足す → `providers/base.py` の `Fundamentals` に項目を追加し、`layers.py` の指標リストに `(名前, 方向, 重み)` を足す
- 配点を変える → `layers.py` の `LAYER_WEIGHTS`（合計100であることをテストが検証）
- 割高キャップを変える → `aggregate.py` の `price_grade_of()`
